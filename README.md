# Songhee Seo — Research Website

GitHub Pages용 정적 사이트입니다. 별도 빌드 없이 그대로 올리면 됩니다.

## 게시 방법
1. GitHub에서 새 저장소를 만듭니다. 이름을 `<내 GitHub 아이디>.github.io` 로 하면 주소가 `https://<아이디>.github.io` 가 됩니다.
2. 저장소 페이지에서 **Add file → Upload files** 를 누르고, 이 폴더 안의 파일 전체(index.html, assets 폴더, .nojekyll)를 끌어다 놓은 뒤 **Commit changes**.
3. **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 저장.
4. 1~2분 후 위 주소로 접속하면 사이트가 열립니다.
